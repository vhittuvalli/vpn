Demo keys last one hour or 500 MB. Traffic leaves from my server in India; it logs when each key was issued and to which IP, not which sites you visit.

What it does

  • Post-quantum encryption. ML-KEM-768 and ML-DSA-44 on top of X25519, in a WireGuard-style protocol.
  • On and off from the menu bar or system tray, with time connected, data used and ping.
  • Kill switch. Blocks all traffic outside the tunnel if the connection drops. Always on, on Windows.
  • Disguise as web traffic. Tunnels over HTTPS on port 443 for networks that block VPNs.
  • Allow local network (Mac). Printers, AirDrop and your router keep working.
  • Trusted networks (Mac). Pauses on networks you trust and reconnects everywhere else.
  • Your own server. On Linux, sudo vpn setup prints an access key; sudo vpn invite NAME adds people.
